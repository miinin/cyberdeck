## Tarkistettu ja OK
- Otsikkorakenne HaveWantViewissä (h1 → h2 Want/Have → h3 haku), fokus h1:een sisääntullessa, fokus h2:een rivin poiston jälkeen, aina-mountattu `role=status` live: hyvä.
- SortSelect: label + toinen select `aria-label`; hyvä.
- AddMissingToWants: aina-mountattu `aria-live` -span, kontekstinimi `aria-label`-propilla; huomio: jos `name` poikkeaa näkyvästä tekstistä, nimen tulee alkaa näkyvällä tekstillä (2.5.3 Label in Name), tarkista kutsujat.
- ExportButtons: `aria-expanded`, `aria-controls`, nimi sisältää pakan nimen, ikoni `aria-hidden`; kosketuskohde --target-min 2.75rem.
- Kielivalitsin: `aria-pressed`, `lang` per painike, ryhmän nimi.
- Teksteissä fi/en on avaimet pareittain (rakenteellisesti); kääntämättömiä kohtia ei havaittu paitsi UX-M9 sekakieli fi:ssä.

# Kuvat, joita tarvitaan

Tarvitsen kuvat **207 korttiversiosta** (88 korttia). Niistä **136** on lähes varmasti uutta kuvitusta (★). Loput 71 ovat starter-, demo- tai muiden pakkojen uusintapainoksia, jotka voivat näyttää samalta kuin perusversio. Jos ne näyttävät samalta, ohita ne.

**Näin toimit:**

1. Etsi kuva.
2. Tallenna se harmaalla näkyvällä tiedostonimellä (pääte .png, .jpg tai .webp) yhteen kansioon.
3. Aja `npm run cards:images -- <kansio>`.

Koneluettava versio hakuohjelmalle: [card-variant-images.json](card-variant-images.json).

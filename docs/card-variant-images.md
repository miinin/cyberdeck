# Korttien versioiden kuvat (T-072)

Tällä listalla ovat ne korttiversiot, joista sovelluksessa ei vielä ole omaa kuvaa. Perusversion kuva (Welcome to Night City) on jo olemassa jokaisesta 151 kortista. Beta-, Retail- ja ranskankielinen (FR) versio käyttävät samaa kuvaa, joten niitä ei listata erikseen.

**Tiedostonimi:** tallenna kuva sarakkeen "Tiedostonimi" mukaisella nimellä (pääte .png, .jpg tai .webp) samaan kansioon, ja aja `npm run cards:images -- <kansio>`.

**Uusi kuvitus?** "kyllä" = eri taiteilija tai erikoisharvinaisuus (Nova Rare, Iconic, Secret, a/b-versio), joten kuva on lähes varmasti erilainen. "ehkä" = starter-, demo- tai muun pakan uusintapainos, joka voi olla sama kuva kuin perusversio. Jos se on sama, kuvaa ei tarvitse etsiä.

Versioita on 207, joista 136 on todennäköisesti uutta kuvitusta.
